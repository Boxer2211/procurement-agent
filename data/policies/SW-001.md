## 1. Scope
### 1.1 Covered purchases
This policy covers perpetual licences, subscriptions, SaaS tools, browser extensions and API services, including free trials that will process company data.

## 2. Duplication and licensing
### 2.1 Existing tools
Before buying new software, the requester must confirm that no tool already licensed by the company covers the need. The current catalogue includes: Jira, Confluence, Slack, Google Workspace, GitHub, Figma, 1Password and Zoom.

### 2.2 Licence count
The number of seats must match named users. Requests must list the users or the team and headcount that will use the licences.

## 3. Security
### 3.1 Security assessment
Any SaaS tool that stores or processes company, customer or employee data requires a security assessment by IT Security before purchase. The assessment checks SOC 2 or ISO 27001 certification, data residency and SSO support.

### 3.2 Data processing agreement
Vendors processing personal data must sign a data processing agreement (DPA).

## 4. Commercial terms
### 4.1 Annual commitments
Subscriptions with an annual value above $10,000 require Legal review of the terms and must include a termination clause.
